# Veille Technologique : Jira

### Comprendre l'outil de gestion de projet d'Atlassian

- **Technologie** : Atlassian Jira
- **Objectif** : Organiser les tâches et suivre les projets en équipe
- **Niveau** : Débutant (Français A1)

---

# 1. Introduction

### Qu'est-ce que Jira ?

- **Jira** est une application web créée par l'entreprise **Atlassian**.
- Cet outil aide les équipes de développement à planifier leur travail.
- Chaque travail ou problème est enregistré dans une fiche appelée **ticket**.
- Jira est utilisé par de nombreuses entreprises dans le monde.

---

# 2. Problèmes Rencontrés

### Le travail en équipe sans outil adapté

- **Informations dispersées** : les tâches sont mélangées dans les e-mails et les messages.
- **Manque de clarté** : l'équipe ne sait pas toujours qui travaille sur quelle tâche.
- **Perte de bugs** : les erreurs techniques sont oubliées ou traitées en retard.
- **Visibilité faible** : le responsable du projet ne voit pas l'avancement en temps réel.

---

# 3. Solutions Apportées

### Comment Jira résout ces difficultés

- **Centralisation** : toutes les tâches et les bugs sont réunis au même endroit.
- **Tableaux visuels** : utilisation de tableaux **Kanban** et **Scrum** faciles à lire.
- **Colonnes simples** : les tickets bougent de **À faire**, vers **En cours**, puis **Terminé**.
- **Responsabilités claires** : chaque ticket a une personne assignée et une priorité.

---

# 4. Exemple Pratique

### Cycle de vie d'un ticket : de l'erreur à la solution

1. **Création du ticket** : un testeur signale le bug `JIRA-101` (*"Corriger le bouton de connexion"*).
2. **Prise en charge** : le développeur place le ticket dans la colonne **En cours**.
3. **Résolution du code** : le développeur corrige le problème et teste la page.
4. **Validation finale** : le ticket passe dans la colonne **Terminé**.
